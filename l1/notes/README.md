# L1 notes intake

Drop raw class material here as-is: typed notes (`.txt`/`.md`), photos/screenshots of slides or the
board, handouts (PDF), and test/quiz reviews (what you missed and why, like `autotrans/notes/unit2.txt`).

- Any filename is fine. Claude reads them, never rewrites or renames them, and logs what was processed
  in `../CONTEXT.md`.
- Corrections and outside sources go in `../research.md`, not in these files.
- Outside references you didn't write (manuals, articles, third-party PDFs) go in `../sources/`.
- Generated guides, sheets and PDFs land in `../study/` (ASE package in `../study/ase/`).
