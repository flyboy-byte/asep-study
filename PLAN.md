## Design choices

Use ordinary files with one combined research record. Preserve raw notes. Let instructor coverage govern class prep and the official exam task list govern ASE breadth. Learn from private or public notes while verifying important claims. Keep private records and restricted source material local. Selected original course notes and guides can be shared intentionally after content review; coursework is not categorically excluded.

The course generator is optional. Existing course folders can adopt the roles without moving material. No background scheduling, hosted service, API calls, or automated exam enrollment is part of the framework.
