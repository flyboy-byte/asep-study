# Automotive study material

This folder contains course and ASE preparation material. Start with `CONTEXT.md`, then `WORKFLOW.md` and `research.md`. Preserve raw notes. Follow the learner's current mode and timing; framework-only status does not authorize starting future course work.

The `ase-study` skill supports this process when installed. Class guides follow instructor scope; ASE guides use the whole relevant corpus and verified official coverage. Notes may come from the learner, public teaching resources, or both. Keep evidence, inference, source access and learner understanding distinct. Update the context handoff after meaningful work.
