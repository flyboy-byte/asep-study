# Image-derived automatic-transmission notes

This folder was created on **2026-09-22** to turn the supplied screenshots into readable Markdown while keeping every original image available for checking diagrams and labels.

## Folder contents

- [`notes.md`](notes.md) — organized notes from the image set, including the range-reference chart, ratio progression, clutch-change pattern, Park/Reverse/Neutral distinctions, and general planetary-gear rules.
- [`images/`](images/) — the 15 original PNG files, moved here without renaming.
- `../notes/powerflowetc.txt` — intentionally left in the older `notes/` directory. The user asked that `.txt` files be ignored, so it was neither read nor used in `notes.md`.

## What was done

1. Inventoried the 15 PNG screenshots and placed them in timestamp order.
2. Identified the sequence: range-reference chart, Park, Reverse, Neutral, 1st through 10th gear, and one general planetary-gear chart.
3. Transcribed the visible range chart, clutch names, ratios, one-way-clutch states, and planetary-gear rules.
4. Reorganized those details into broader study notes and shift-to-shift patterns.
5. Added a source-image link beside each topic so a reader can return to the original diagram.
6. Preserved the original filenames so later notes can cite an image unambiguously.

## Accuracy and source boundaries

- These are **image-derived course notes**, not outside research and not a complete service procedure.
- The GM/ACDelco slide text appears in scrollable panels. Several screenshots show only the portion visible when the screenshot was taken, so `notes.md` does not claim to reproduce missing off-screen text.
- The transmission model number is not visible in the supplied screenshots and was not guessed.
- Ratios and clutch applications are recorded as displayed. The range-chart slide itself warns that calibration changes can make functional clutch names inaccurate, so vehicle-specific diagnosis still requires current Service Information.
- The general planetary chart is summarized for study; the original remains in `images/` for visual checking.

## Adding more image notes

Place future screenshots in `images/`, retain descriptive or timestamped filenames, and add their concepts to `notes.md`. Record what is directly visible, mark anything uncertain, and keep outside corrections or research separate from the learner's supplied material.
