## What are the general principles of TCM programming and why is it needed after certain repairs?

### Takeaway
A replacement or used TCM/TEHCM must be flashed with the software/calibration that matches the vehicle's VIN (and, on newer units, loaded with solenoid/valve-body characterization data), and software updates are delivered the same way. Programming is done with the OEM tool or an SAE J2534 pass-thru device plus an OEM software subscription, on a stable regulated power supply, without interruption; a voltage drop mid-flash can leave the module unusable.

### Cited Findings
- DOCUMENTED / UNIVERSAL: SAE J2534 is the SAE "Recommended Practice for Pass-Thru Vehicle Programming": OEM software on a PC talks to the vehicle through a compatible vehicle communication interface (VCI) to reprogram ECUs. — [SAE J2534/1_201510](https://www.sae.org/standards/j25341_201510-recommended-practice-pass-thru-vehicle-programming); [AutoPi J2534 explainer](https://www.autopi.io/blog/j2534-explained/)
- DOCUMENTED / UNIVERSAL (US regulatory): US EPA regulation requires OEMs to support J2534 pass-thru reprogramming of powertrain ECUs from model year 2004 forward, available to anyone in the US for emissions-related controllers. — [DG Technologies J2534 FAQ](https://www.dgtech.com/j2534-reprogramming-faq/); [Bosch Diagnostics J2534 FAQ](https://www.boschdiagnostics.com/j2534-faq)
- DOCUMENTED / UNIVERSAL: Equipment listed for pass-thru reflashing is a reliable internet connection, a dedicated laptop, an OEM software subscription (reached via NASTF.org), and a J2534 interface. NASTF hosts J2534 reprogramming information. — [VehicleServicePros: J2534 reflashing resource](https://www.vehicleservicepros.com/distribution/article/20970407/become-a-resource-for-j2534-reflashing-and-j2534-reprogramming); [Underhood Service: NASTF J2534 info](https://www.underhoodservice.com/nastf-website-features-j2534-reprogramming-information/)
- DOCUMENTED / UNIVERSAL: A battery maintainer supplies steady voltage during the programming event. Use clean power without spikes, and "never use a regular battery charger", because AC ripple can damage the module being updated. — [VehicleServicePros: parts replacements and J2534](https://www.vehicleservicepros.com/service-repair/diagnostics-and-drivability/article/20972876/vehicle-parts-replacements-and-j2534-vehicle-reprogramming); [FenderBender: dos and don'ts of J2534](https://www.fenderbender.com/running-a-shop/operations/article/33028425/dos-and-donts-of-reprogramming-with-a-j2534-compliant-device)
- DOCUMENTED / UNIVERSAL: A sudden voltage drop can make programming fail and can leave the module unusable. Follow the OEM's requirements for voltage, current capacity and connection method. — [MyCarHeaven J2534 checklist (2026-09)](https://mycarheaven.com/2026/09/before-you-start-j2534-pass-thru-programming-a-checklist-for-independent-workshops/) (vendor/blog source; the principle agrees with the sources above)
- DOCUMENTED (secondary, number not OEM-verified): "Most OEMs recommend" about 13–14 V from a regulated supply during programming. — search summary of the J2534 result set above, including [diag.net "Battery Voltage & J2534 Programming"](https://diag.net/msg/m1fcqy8yfs38i6kzqc14q9m9pr). **NEEDS SI**: the actual voltage window varies by OEM and tool.
- DOCUMENTED / GM-SPECIFIC: After replacement or major service, a 6L80/6L90 TEHCM must be flashed to the vehicle's VIN and calibration so it shifts correctly and communicates with the ECM/BCM. Listed tools: GM Service Programming subscription (ACDelco TDS), a J2534/MDI2 interface, a stable battery maintainer, and a laptop with internet. — [Monster Transmission: Why you must program a 6L80](https://monstertransmission.com/pages/why-you-must-program-a-6l80)
- DOCUMENTED / GM-SPECIFIC: A remanufactured 6L80/6L90 TEHCM "must be reprogrammed on the vehicle using a J2534 device in order to function correctly". — [Sonnax GM6L-TEHCM-C6 instructions (PDF via Summit)](https://static.summitracing.com/global/images/instructions/sox-gm6ltehcmc6.pdf)
- DOCUMENTED / GM-SPECIFIC: A used TEHCM still holds a program tied to a different VIN. The programming session must use "Replace and Reprogram", not just "Reprogram", so the program for the correct VIN overwrites it and the latest updates install. — [Sonnax GM6L-TEHCM-C5 instructions (PDF)](https://d2q1ebiag300ih.cloudfront.net/uploads/part/5647/GM6L-TEHCM-C5-IN.pdf?v=1724962505417)
- DOCUMENTED / GM-SPECIFIC: 6T70/6T75 valve bodies come in many calibrations, so the VIN is needed to program the unit correctly. The replacement TEHCM must be programmed with the proper, latest software/calibration per OE instructions, then an adaptation reset/relearn is done with a scan tool. — [Street Smart Transmission 6T70/6T75 TEHCM](https://streetsmarttransmission.com/remanufactured-6t70-6t75e-valve-body-gppc/); [Sonnax GM6T70-G2-TEHCM](https://www.sonnax.com/parts/5880-remanufactured-tehcm)
- DOCUMENTED / GM-SPECIFIC: GM 6-speed Service Fast Learn is required after a "TCM software/calibration update", among other repairs. — search summary of GM Technical Bulletin #1392 (6L45/6L50/6L80/6L90), hosted as a [forum attachment](https://www.e90post.com/forums/attachment.php?attachmentid=3482186&d=1718730748). Secondary hosting; verify in GM SI.

### Inferences
- INFERRED / UNIVERSAL: Across makes, TCM programming falls into three triggers: (1) a new, reman or used module that needs a VIN-correct calibration (a "replace and program" or configure event); (2) a software update issued by bulletin, TSB or campaign (a "reprogram" of the same module); (3) newer designs where a hard-part change (valve body, solenoid body, whole transmission) requires loading new part-specific characterization data even though the module itself did not change. Each trigger is usually followed by clearing adapts and a relearn.
- INFERRED / UNIVERSAL: For exam reasoning, "stable voltage from a maintainer (not a charger), don't interrupt the session, correct VIN and calibration, then relearn" is the portable principle. Tool menu names, subscription portals and exact voltage windows are OEM detail.

- OPEN: Did not confirm whether any OEM formally requires "programming-capable" maintainers by amperage rating. Sources give it only as a general recommendation.

## What is solenoid body / valve body calibration ID data, which manufacturers use it, and what happens if it isn't loaded?

### Takeaway
Solenoids are flow-tested at manufacture and given calibration ("banding"/characterization) data. The TCM needs that data to command each solenoid correctly. Ford uses a 13-digit Solenoid Body Strategy plus a Solenoid Body ID (6F/6R families from MY2005 on, and the 10R family). GM uses serialized characterization data for the 8L45/8L90 (PUN/TUN codes, retrieved from GM's server by VIN) and ties TEHCM calibrations to the VIN on the 6L/6T families. If the data is missing or mismatched, the result is harsh or flared shifts, slow adaptation, possible DTCs, and possible transmission damage.

### Cited Findings
- DOCUMENTED / UNIVERSAL (design principle): When solenoids were grouped into assemblies, it became cost-effective to measure each solenoid's flow against electrical input and assign a calibration number. The manufacturer can then match a control algorithm to that number, which lets more solenoids fall in the acceptable range. — search summary of [Gears Magazine: Ford Solenoid Strategy Numbers](https://gearsmagazine.com/magazine/ford-solenoid-strategy-numbers-is-it-necessary-to-program/) and [Sonnax: Basics of Banded Solenoids](https://www.sonnax.com/tech_resources/1209-breaking-down-the-basics-of-banded-solenoids)
- DOCUMENTED / FORD-SPECIFIC: Ford introduced solenoid strategies in MY2005 with the 6F50N family, then added the 6F35N, the 6R80 family and the 6R140. — search summary of the [Sonnax Ford Solenoid Strategy webinar PDF](https://d2q1ebiag300ih.cloudfront.net/uploads/tech_resource/file/549/Sonnax_Webinar_PPT_6F_6R_Ford_Solenoid_Strategy.pdf?v=1521493563)
- DOCUMENTED / FORD-SPECIFIC: The 6R140 uses a 13-digit solenoid body strategy and an 8-digit solenoid body identification. Both are on a tag on the valve body and on the side of the case. Programming them tells the TCM which band solenoid sits in each position. — [Sonnax: 6R140 Solenoid Strategy Code](https://www.sonnax.com/tech_resources/848-6r140-transmission-solenoid-strategy-code-don-t-break-up-the-band); [Transmission Digest: TASC Force Tips (6R140)](https://www.transmissiondigest.com/tasc-force-tips-4/)
- DOCUMENTED / FORD-SPECIFIC: The procedure uses the replacement valve body's strategy number and body ID. The new solenoid strategy file is uploaded to the TCM with a Ford scan tool or J2534 device, then the adaptive tables are cleared and transmission keep-alive memory (KAM) is reset. — search summary of the Sonnax/Gears Ford strategy result set (same URLs as above)
- DOCUMENTED / FORD-SPECIFIC (10R family): When the valve body or just the solenoids are replaced on a 10R80/10L90, the TCM must be updated. The 13-digit solenoid-body strategy number shown on the scan tool must match the number etched on the main control. The entry screen has fields for a 12-digit solenoid body ID and the 13-digit strategy. "If the numbers do not match, damage to the transmission or driveability concerns can occur." — [Transmission Digest: 10R80/10L90 Solenoid Function](https://www.transmissiondigest.com/10r80-10l90-10-speed-solenoid-function/); [Gears Magazine: 10R60/10R80/10R140 solenoids](https://gearsmagazine.com/magazine/direct-connection-10r60-10r80-and-10r140-solenoids-make-shifts-happen/)
- CONFLICT / FORD-SPECIFIC: The digit count of the Solenoid Body ID varies between sources: 8-digit for the 6R140 (Sonnax), 12-digit on 10R/6R entry screens (Transmission Digest / rebuilder summaries), and a "7 digit" number mentioned in a [diag.net 10R80 thread](https://diag.net/msg/m4otok7x9hhgujfndrmg8tp536) (technician forum, low weight). It probably differs by family. NEEDS SI for the specific unit.
- DOCUMENTED (forum, low weight) / FORD-SPECIFIC: The diag.net thread says the 10R80 strategy and ID numbers are on the valve body "nowhere near the QR code". I found no reliable source saying Ford uses a QR code *scanned* by the scan tool for strategy entry. — [diag.net 10R80 Solenoid Body Strategy](https://diag.net/msg/m4otok7x9hhgujfndrmg8tp536)
- DOCUMENTED / FORD-SPECIFIC (consequence): The 6R80/6R140 variable bleed solenoids can drift from their calibration ("banding") over time, which disrupts shift control, overlap and adaptation. A mis-banded solenoid with slow or overly aggressive output can cause a 1-2 slide or a very harsh 1-2 upshift, and also a 2-3 flare or bind-up through its effect on clutch release rate. Installing solenoids with arbitrary band numbers can produce flares or harsh shifts that take longer than desired for the TCM to adapt out. — [Sonnax: Troubleshooting 6R80/6R140 timing-related shift issues](https://www.sonnax.com/tech_resources/1137-troubleshooting-ford-6r80-6r140-timing-related-shift-issues); [Transmission Digest version](https://www.transmissiondigest.com/ford-6r80-6r140-troubleshooting-timing-related-shift-issues/)
- DOCUMENTED / GM-SPECIFIC (8L45/8L90): The 8-speed solenoids need unique performance characteristic data, stored in the TCM, to work at maximum efficiency. If the transmission, valve body, solenoids or TCM is changed, the data must be downloaded from GM's web server (TIS2Web / Service Programming System) and the TCM reprogrammed. The TCM uses a current-modulation algorithm to control solenoid flow. — GM TechLink "Reprogramming Procedures for the 8L90 8-Speed Transmission", as reproduced at [Corvette Action Center](https://www.corvetteactioncenter.com/tech/knowledgebase/article/2015-corvette-gm-techlink-reprogramming-procedures-for-the-8l90-8-speed-transmission-1198.html) (a reprint of the GM TechLink article; original TechLink URL not located)
- DOCUMENTED / GM-SPECIFIC (8L45/8L90): A Part Unique Number (PUN) is on the valve body and solenoids and a Transmission Unique Number (TUN) is on the case. The system reads the VIN from the ECM through the MDI and pulls the genealogy data for that TUN/PUN from the cloud. The 8L90 valve body has 9 solenoids: 7 variable-force pressure-control and 2 on/off. — [Gears Magazine: PUN – Programming and Part Numbers on 8L45/8L90 Solenoids](https://gearsmagazine.com/magazine/now-that-was-a-good-pun-programming-and-part-numbers-on-8l458l90-solenoids/); [Gears Magazine: 8L90 Solenoid Strategies](https://gearsmagazine.com/magazine/8l90-solenoid-strategies/)
- DOCUMENTED / GM-SPECIFIC: GM TechLink "Transmission Adaptive Functions" says that when a transmission assembly, valve body or TCM is replaced, reset the shift adapts by refreshing the **Characterization Data** and then completing Transmission Service Fast Learn. — [GM TechLink: Transmission Adaptive Functions (forum reprint)](https://www.cadillacvnet.com/forums/threads/gm-techlink-transmission-adaptive-functions.1132/); related GM bulletin "Information on Transmission Adaptive Functions" at [NHTSA TSB PDF MC-10112288](https://static.nhtsa.gov/odi/tsbs/2016/MC-10112288-9999.pdf) (title seen in search; full text not fetched)
- DOCUMENTED / GM-SPECIFIC (6L80/6L90): Sonnax serializes its remanufactured TEHCMs and keeps each unit's final-test data. Installers are told to log serial numbers. — [Sonnax GM6L-TEHCM-C5 instructions](https://d2q1ebiag300ih.cloudfront.net/uploads/part/5647/GM6L-TEHCM-C5-IN.pdf?v=1724962505417)

### Inferences
- INFERRED / UNIVERSAL: The idea is the same across makes. Mass-produced solenoids vary, so each one is characterized, and the TCM uses that characterization to turn a commanded pressure into the right current. What varies by make is the **delivery method**: Ford has the technician enter the strategy/ID read from a tag; GM (8-speed) pulls the data from the cloud by TUN/PUN and VIN; GM 6L/6T ties the TEHCM (module plus solenoid body in one unit) calibration to the VIN.
- INFERRED: Adaptive learning can partly cover a small mismatch. Sources show it cannot reliably cover a wrong strategy (harsh/flare shifts, slow adaptation, possible damage and DTCs). "Drive it and let it learn" is therefore not a substitute for loading the data.
- INFERRED: The GM 6L80/6T70 TEHCM (solenoids and TCM integrated) is why "replace the TEHCM" is itself a programming event. On the 8L it is the separate valve body/solenoids that carry the PUN.

## What is an adaptive relearn (GM Service Fast Learn, Chrysler Quick Learn, Ford adaptive reset + drive cycle), when is it performed, and what preconditions are typical?

### Takeaway
Adaptive learning ("adapts", Ford "TAP"/adaptive tables, KAM) is the TCM's continuous closed-loop correction of shift pressure and timing, similar to fuel trim. After repairs that change the hydraulic or friction baseline, or after a module or data change, the tech clears adapts and runs a scan-tool-driven learn (GM Service Fast Learn, a stationary test; Chrysler Quick Learn) and/or a prescribed drive cycle (Ford, ZF). Each routine has fluid-temperature and operating-condition preconditions, and the numbers differ by transmission and software. GM explicitly says clearing adapts is **not a repair** for a shift concern.

### Cited Findings
**General / GM principle**
- DOCUMENTED / GM (principle UNIVERSAL): The adapt function is a continuous process that automatically compensates shift quality to keep it optimal over the vehicle's life. It is similar to closed-loop fuel control. — [GM TechLink: Transmission Adaptive Functions (reprint)](https://www.cadillacvnet.com/forums/threads/gm-techlink-transmission-adaptive-functions.1132/)
- DOCUMENTED / GM-SPECIFIC: Clearing and relearning shift adapts "should not be considered a repair process". It is meant only for after a transmission repair. If there is a specific shift concern, Service Fast Learn should not be performed. Instead, complete the appropriate **driving** learn procedure to further learn clutch pressures and volumes. — [GM TechLink: Transmission Adaptive Functions (reprint)](https://www.cadillacvnet.com/forums/threads/gm-techlink-transmission-adaptive-functions.1132/)

**GM Service Fast Learn (SFL)**
- DOCUMENTED / GM-SPECIFIC (8-speed): Transmission Service Fast Learn runs after any 8-speed repair as a series of tests that let the TCM learn individual clutch apply pressures, which it uses for clutch control and shift timing. It erases adapt values to baseline, which must then be relearned. — [Sonnax: Tips for Success with GM Transmission Fast Learn](https://www.sonnax.com/tech_resources/1322-tips-for-success-with-the-gm-transmission-fast-learn-process); [Transmission Digest version](https://www.transmissiondigest.com/tips-success-gm-transmission-fast-learn-process/); GM TechLink 8L90 reprint (above)
- DOCUMENTED / GM-SPECIFIC (8-speed triggers): pressure regulating solenoid replacement, valve body repair or replacement, any service for a shift quality concern, any internal service/overhaul/replacement, torque converter replacement, TCM replacement, transmission assembly replacement. — search summary of the Sonnax/Transmission Digest SFL article (above)
- DOCUMENTED / GM-SPECIFIC (8-speed preconditions): The scan tool will not run SFL unless transmission fluid temperature is between **167 °F (75 °C) and 185 °F (85 °C)**. Line pressure must be normal (**55–60 psi minimum** with rise on throttle in Drive), and ATF level must be correct and verified. SFL is a stationary in-bay process started with a scan tool or J2534 pass-thru. — search summary of the [Sonnax SFL article](https://www.sonnax.com/tech_resources/1322-tips-for-success-with-the-gm-transmission-fast-learn-process). Applies to the GM 8-speed unit(s) that article covers. **NEEDS SI** before quoting.
- DOCUMENTED / GM-SPECIFIC (6-speed, 6L45/6L50/6L80/6L90): Service Fast Learn Adapts runs tests so the TCM learns individual clutch characteristics and writes them into adaptive cells. Required after internal service/overhaul, valve body repair/replacement, control solenoid valve assembly replacement, TCM software/calibration update, or service for a shift quality concern. Skipping it "may result in poor transmission performance, as well as transmission DTCs being set". Preconditions: drive wheels blocked, parking and service brakes applied, 0% throttle, no external engine rpm control, and the selector cycled Park–Reverse 3 times to purge air from the reverse clutches. — search summary of GM Technical Bulletin #1392, [forum-hosted attachment](https://www.e90post.com/forums/attachment.php?attachmentid=3482186&d=1718730748). Secondary hosting.
- CONFLICT / GM-SPECIFIC (6-speed temp window): The same 6L-family result set gave TFT **70–115 °C (158–239 °F)** and also **75–85 °C (167–185 °F)** "depending on current TCM programming". — [forum-hosted GM TB #1392](https://www.e90post.com/forums/attachment.php?attachmentid=3482186&d=1718730748); [Core Transmission Parts: 6L80 adapt reset](https://coretransmissionparts.com/blogs/news/6l80-adapt-reset-procedure-force-tcm-relearn-after-repairs). I could not resolve which applies to which calibration. **NEEDS SI.**
- CONFLICT / GM-SPECIFIC (shift-concern trigger): The SFL trigger lists (8-speed Sonnax summary; 6-speed TB #1392) include "any service in response to a shift quality concern". The TechLink Adaptive Functions article says not to perform SFL for a specific shift concern and to use a driving learn instead. ### Inferences
- INFERRED / UNIVERSAL: The standard post-repair sequence across makes is: verify correct fluid level and fluid condition, then program or configure the module and load characterization data if required, then clear adapts, then run the OEM learn (stationary scan-tool routine and/or prescribed drive cycle) inside its fluid-temperature window, then road-test and recheck codes.
- INFERRED / UNIVERSAL: Relearns have fluid-temperature windows because clutch fill time and apply pressure change with fluid viscosity. A learn done cold or hot would store values that are wrong at normal operating temperature. This matches every procedure found having a TFT gate, although the numbers differ.
- INFERRED / UNIVERSAL: Low fluid, low line pressure, or a mechanical/hydraulic fault makes a learn fail or store bad values. That is why the GM SFL article sets fluid-level and line-pressure preconditions. Fix the root cause first.
- INFERRED (exam framing): A typical Tech A/Tech B pairing would be "clearing adapts fixes the harsh shift" vs "adapts must be relearned after the valve body is replaced". By GM's stated principle, the second is correct and the first is not a repair.

## Which parts are universal principle vs. manufacturer-specific?

### Takeaway
The universal principles are: a module needs a VIN-correct calibration; software updates arrive by reflash; J2534 or OEM tools do the flashing; power must be clean and stable; the session must not be interrupted; solenoids are characterized and the TCM must know that characterization; adapts are a closed-loop correction that is cleared and relearned after hard-part or module changes but is not a repair in itself; and relearns have temperature and operating preconditions. Code names, digit counts, menu names, temperature windows, pressures, drive-cycle steps and which repairs trigger which routine are manufacturer-specific and come from Service Information.

### Cited Findings
- DOCUMENTED / UNIVERSAL: J2534 is an SAE recommended practice, and EPA requires OEM support for powertrain ECUs from MY2004. — [SAE J2534/1](https://www.sae.org/standards/j25341_201510-recommended-practice-pass-thru-vehicle-programming); [DG Technologies FAQ](https://www.dgtech.com/j2534-reprogramming-faq/)

### Inferences
- INFERRED: For the A2 exam, which follows the task list rather than a single OEM, the testable content is most likely the universal layer: why programming or configuration is needed after TCM, valve body or solenoid replacement; J2534 and stable-voltage practice; that adapts must be relearned after repair; that clearing adapts isn't a fix; and that relearns need correct fluid level and temperature. OEM menu names and numbers are unlikely to be tested verbatim. This is an inference about exam style; it was not verified against ASE material, and no secure ASE content was used.
- INFERRED: The terms map across makes: GM "adapts / Service Fast Learn / characterization data", Ford "adaptive tables / KAM reset / solenoid body strategy", Stellantis "adaptives / Quick Learn". The functions are equivalent; the names are OEM-specific.
