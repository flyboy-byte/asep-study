# Adapting the framework across subjects

Framework status: reusable approach; no completed A2, A8, or L1 curriculum is included.
Official reference routes checked: 2026-09-16. Future learners must verify the then-current requirements and guide editions.

## Starting another course

Reuse the process, not the previous course's conclusions. Start a fresh local context with the actual exam, instructor scope, textbook/edition if known, lab assemblies, learner experience, dates, and current material. Leave unavailable facts unknown. Bring across only relevant mechanisms with their original source and design boundary.

Create a course folder when requested, then begin intake and research according to the learner's timing. A discussion of next term can remain a documented plan without downloading a curriculum, generating questions, or inventing deadlines.

## Subject adaptations

The following are proposed organizing lenses, not claims about individual-question frequency:

| Path | Preserve from prior study | Develop from the new course and verified sources |
|---|---|---|
| Manual drivetrain → automatic transmission (A2) | Gear relationships, friction elements, measured clearances, evidence-based diagnosis | The identified automatic unit's power flow, hydraulic/control interactions, apply information and diagnostic observations. |
| Earlier A-series work → engine performance (A8) | Electrical reasoning, mechanical fundamentals, inspection habits and relevant prior shop experience | Connections among symptoms, operating conditions, engine systems, data and discriminating tests. Follow the actual instructor's sequence. |
| Engine performance → advanced engine performance (L1) | A8 explanations and well-understood diagnostic methods | Practice applying the current L1 reference to a case, reconciling evidence and choosing the next check. |

## L1 has its own reference and requirements

ASE currently requires passing A8 to register for initial L1. Many L1 questions use the **Composite Vehicle Type 4** reference, available as an electronic pop-up during the test. Check the [official L1 page](https://ase.com/tests/l1/) for the current study guide and reference links. Registration prerequisites, certification work-experience requirements, and a school's funding rules are distinct; verify each that matters to the individual learner.

The [Composite Vehicle reference](https://ase.com/wp-content/uploads/L1_CV4.pdf) describes a constructed design rather than one production make/model. For a question identified as using the composite, use that reference's stated behavior instead of importing a familiar GM or other vehicle's rules. This source's introduction was checked; the framework does not claim a complete technical audit of the reference.

When L1 preparation is actually requested, verify the active guide/reference editions, map the task coverage, and develop original cases requiring reference use. Label hypothetical data, cite the supporting reference location, and explain why each proposed next test would distinguish the remaining causes. Do not present it as a recalled or official secure test item.

The framework sets no semester, exam appointment, requirement to pass all nine A-series tests, or funding promise. Record a learner's actual schedule and institution-specific arrangement only in their local context.
