# ASEP Study Workflow repository

This is the reusable public framework, not an individual's study folder. Read the README for entry points and `skills/ase-study/references/design.md` for intent. The skill and its references are the canonical workflow; avoid maintaining a second copy of their detail.

Keep personal records and third-party restricted content local by default. Selected learner-authored notes, original guides and examples can be published when the user authorizes sharing and their contents have been reviewed for source rights and identifying details. Do not turn this default into a blanket ban on sharing coursework. Course work belongs in a separate local folder created only when requested. Subject pathways describe future use, not a completed curriculum or proof of exam readiness.

The generator is dependency-free Python 3.9+. Verify creation in a temporary folder, refusal of an existing destination, and generated-file completeness when changing it. For skill changes validate frontmatter and references, and review realistic modes including framework-only and web-first requests. Do not fabricate source access, test outcomes or assistant runtime validation.
